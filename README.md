# BidiAI Web App - Vercel Gateway

Dự án cổng chuyển tiếp (Reverse Proxy Gateway) đưa website **BidiAI** từ máy chủ Mac mini (`https://mac-mini-of-datvy.tailef1cd5.ts.net/`) lên tên miền miễn phí của **Vercel** (`*.vercel.app`).

## 🚀 Triển khai 1-chạm lên Vercel

Bấm vào nút bên dưới để tạo tên miền Vercel miễn phí ngay lập tức:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fbidikid77-hub%2Fbidiai-web)

Hoặc:
1. Đăng nhập vào [Vercel Dashboard](https://vercel.com).
2. Bấm **Add New...** -> **Project**.
3. Chọn kho mã nguồn `bidikid77-hub/bidiai-web` và bấm **Deploy**.
4. Bạn sẽ nhận được tên miền miễn phí như `https://bidiai-web.vercel.app` hoặc tùy chỉnh tên theo ý muốn.
